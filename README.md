# SJscanner — نسخة الويب

ماسح مستندات يعمل من المتصفح ويُثبَّت على الشاشة الرئيسية للآيفون كتطبيق:
قص تلقائي للحواف، تصحيح الميلان، فلاتر، حفظ ومشاركة PDF، واستخراج النص (عربي وإنجليزي).

كل الصور والمستندات تُحفظ على جهازك فقط، ولا تُرفع إلى أي خادم.

## التشغيل
الموقع يُنشر عبر GitHub Pages من فرع `main`.
